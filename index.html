Questions

Is it really free?
Yes. No trial, no subscription, no ads and no sign-up.
Where do I download it?
From the Microsoft Store: click Get it from Microsoft on this page. It installs in one click, is checked by Microsoft, and shows no security warnings.
Can it format my essay in MLA or APA?
Yes. Open your essay (Word, PDF or a new document), choose Format → Style guide and pick MLA 9, APA 7, Chicago or Harvard. It sets the title page, font, spacing, margins and page numbers, and builds the reference list. Cite a source writes each entry and the in-text citation for you, and Check my format lists anything left to fix.
How do I get updates?
Automatically. The Microsoft Store keeps Document Studio up to date in the background. Your documents and settings stay as they are.
Does it need the internet?
No. Everything runs on your PC, including text recognition on scanned PDFs and flowchart drawing. Your documents are never uploaded anywhere.
Do I need Microsoft Office?
Not for most things. Creating documents, editing PDFs, OCR, Gantt charts, flowcharts and exporting to PDF, Word, Markdown or pictures all work without it. Converting Word, Excel or PowerPoint files, and “Edit as document” for PDFs, use Microsoft Office if it's installed on your PC.
Which Windows versions does it run on?
Windows 10 (version 1809 or later) and Windows 11, 64-bit.
How can I suggest a feature or report a problem?
Use Send feedback. It opens a short form on GitHub (a free GitHub account is needed). See What's new for the latest changes.
How do I uninstall it?
Settings → Apps → Installed apps → Document Studio → Uninstall. Your documents are kept.
