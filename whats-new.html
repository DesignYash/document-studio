What's new

Every update to Document Studio, newest first. Updates install automatically from the Microsoft Store.

Version 1.0.2 Latest

October 2026 · live on the Microsoft Store — updates install automatically
  • Page curl — drag a page's corner in the PDF editor or PDF preview and it peels like real paper to turn the page
  • Templates open faster — the card you pick flies up and becomes your document, smoothly
  • Style guides that move — switching between MLA, APA, Chicago and Harvard, every line travels to its new place
  • Ink loading screen — ink pours into the page while Word, PDF and Excel files open
  • Pen-written signatures — your signature is written onto the page by a pen, then stamped
  • Ink delete and undo — deleted blocks break into ink; Undo pulls the ink back together
  • Time machine — fly back through your saved versions in 3D from Version history
  • Cards and main buttons respond to the pointer with depth and light

Version 1.0.1

October 2026 · live on the Microsoft Store — updates install automatically
  • Style guides for essays and papers — format any document as MLA 9, APA 7, Chicago or Harvard in one click: title page or heading block, font, line spacing, margins, page numbers and the reference list on its own page
  • Cite a source — fill in a book, website, journal article or chapter and get the reference-list entry plus the in-text citation, or a numbered footnote for Chicago
  • Check my format — a checklist of anything that doesn't follow the style yet, with Fix all
  • Save the paper as Word or PDF, already in its style
  • An animated loading screen while Word, PDF and Excel files open
  • Much smoother menus, pop-ups and hover effects
  • Fixed: the Save button turning white when you point at it

Version 1.0

October 2026 · first release on the Microsoft Store
  • 14 document templates plus a blank page — reports, letters, invoices, minutes, CVs, proposals, manuals, test reports and more
  • PDF editor: change the words already in a PDF, add text, highlights, boxes, pictures and signatures, fill forms, reorder pages
  • Text recognition (OCR) for scanned PDFs, offline
  • Convert between Word, PDF, Excel, PowerPoint, pictures, web pages, Markdown and text
  • Gantt chart maker with phases, milestones and dependencies
  • Flowchart maker (Mermaid) with a visual style editor
  • Four themes and eleven gradient colour palettes
